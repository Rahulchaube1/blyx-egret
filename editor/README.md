# Blyx Egret

Summarize richness, singletons and dominance in an ecological field survey.

This extension includes the Blyx Egret 0.1.0 source, a runnable example and completions for its public functions. It uses the Blyx Language extension for syntax highlighting and execution.

## Run in the editor

1. Open an empty file named `egret-demo.blyx`.
2. Type `blyx-egret-demo` and select **Egret — runnable example**. You can also use **Snippets: Fill File with Snippet**.
3. Choose **Blyx: Run File** from the command palette. Change an argument near the end of `fn main()` to try another input.

Expected output

```text
4
2
0
0.5
2
```

## Use Egret in a project

Extract the starter into a new folder. It contains `main.blyx`, the licensed framework source in `vendor/egret`, and a VS Code task. With the Blyx 0.2.1 compiler and host toolchain installed, run `blyxc native-run main.blyx` from that folder. Type `blyx-egret-` in a Blyx file to see the framework completions. [Download the starter ZIP](https://github.com/Rahulchaube1/blyxxxx/releases/download/framework-editors-v0.1.0/blyx-egret-starter-0.1.0.zip)
