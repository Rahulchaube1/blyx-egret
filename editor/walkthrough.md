## Compare abundance and diversity in a field survey

Returns [individuals, observed taxa, singletons, dominance, effective taxa]. An entirely empty survey has no diversity estimate. Invalid arguments and nonfinite results return an empty vector.

1. Open an empty file named `egret-demo.blyx`.
2. Type `blyx-egret-demo` and select **Egret — runnable example**. You can also use **Snippets: Fill File with Snippet**.
3. Choose **Blyx: Run File** from the command palette. Change an argument near the end of `fn main()` to try another input.

Expected output

```text
4
2
0
0.5
2
```

[Work through the example in the browser](https://www.blyx-lang.space/play?example=package-egret)
