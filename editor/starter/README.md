# Egret starter

Summarize richness, singletons and dominance in an ecological field survey.

Open the extracted folder in VS Code. With Blyx 0.2.1 and its host toolchain installed, choose **Terminal → Run Task → Run Egret** or run the following command in this directory.

```sh
blyxc native-run main.blyx
```

Expected output

```text
4
2
0
0.5
2
```

The vendor directory contains the framework source for 0.1.0 and its license texts. [Read the API guide](https://www.blyx-lang.space/packages/egret) · [View the release](https://github.com/Rahulchaube1/blyx-egret/releases/tag/v0.1.0)
